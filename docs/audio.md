# Звуки M1 (T1.6)

Все 5 звуков синтезированы из WebAudio-кода веб-прототипа (`ball_territory_web/public/index.html`, объект `snd`), портированного в Python: `assets/audio/src/synth.py`. Чужих файлов нет, лицензия — собственная работа проекта, ограничений нет. Файлы: моно, 44,1 кГц, пик −1,5 дБ, тишина обрезана. `.ogg` — Vorbis, `.wav` — PCM16.

**F1 (2026-11-10):** звук захвата клеток убран из игры — он звучал до 8 раз в секунду на каждую закраску и на слух пользователя «постоянно пукал». Захват теперь беззвучный, отклик закраски — только картинка (клетки, частицы). Звуки остались только на редких моментах: сила, реакция, финал, победа. Если когда-нибудь понадобится звук закраски — только очень тихий мягкий тик, не чаще 4 раз в секунду, и сначала дать послушать пользователю. Ассет `sfx_capture` в аккаунте остаётся, в коде (`Render/Sfx.luau`) его нет.

Громкость: все файлы нормализованы одинаково (пик −1,5 дБ), баланс задаётся свойством `Volume` в игре. Значения — стартовые, подстройте на слух.

## Как загрузить (Creator Hub)
1. Откройте https://create.roblox.com/dashboard/creations и войдите под аккаунтом-владельцем игры (или группы, если игра в группе).
2. Выберите Development Items → Audio → Upload Asset (в Studio то же: Asset Manager → Audio → Bulk Import).
3. Выберите файлы `assets/audio/sfx_*.ogg` (если `.ogg` не принят, берите `.wav`). Проверка модерации занимает до нескольких минут.
4. Дождитесь статуса Accepted. Откройте каждый звук и скопируйте Asset ID (число из адреса).
5. Впишите ID в пустую колонку таблицы и передайте файл координатору: luau-coder внесёт их в модуль `SoundIds`.
6. Владелец звука и игры должен совпадать. Для групповой игры загружайте от имени группы.
