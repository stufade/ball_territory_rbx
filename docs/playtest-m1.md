# Плейтест M1: гейт веселья

Цель — проверить гипотезу из брифа: новичок Roblox без объяснений понимает, что управляет шаром и силой, ловит реакцию и сам жмёт «ещё раз». Вердикт PROCEED / PIVOT / KILL выносит пользователь после теста.

## Подготовка (пользователь, ~10 минут)

1. Studio → File → Publish to Roblox, место «Element vs Element».
2. Creator Hub → игра → Settings → Places → максимум игроков 12.
3. Доступ: новая игра открыта только проверенным игрокам 16+ и «доверенным друзьям» (Trusted Friends) автора. Тестеры либо проходят проверку возраста, либо добавляются в Trusted Friends.
4. Перед тестом проверь сам с телефона: зайти, сыграть первый раунд, одну дуэль.

## Кто играет

- 3+ новичка, которые не видели веб-версию, с телефона. Это главная группа.
- 2 друга из веб-теста: сравнить с вебом.

## Как проводить

- Новичку сказать только «зайди в игру». Не объяснять правила, не подсказывать голосом, не отвечать на вопросы до конца первого раунда.
- Смотреть на экран тестера или записывать экран. Засечь время, отмечать вслух сказанное.
- После первого раунда не предлагать играть дальше: смотрим, нажмёт ли он сам.
- Через 10 минут или когда тестер сам остановился — вопросы ниже.

## Что записать по каждому тестеру

| Наблюдение | Да/нет, время |
|---|---|
| Первый тап по полю или смена направления за 30 с без подсказки | |
| Нажал кнопку силы сам | |
| Поймал хотя бы одну реакцию (слово вроде WILDFIRE на экране) | |
| Сам начал следующий матч после первого раунда | |
| Сколько дуэлей подряд сыграл сам | |
| Где растерялся или спросил «что делать?» | |
| Что непонятно на экране телефона | |

## Вопросы после игры

1. Какой момент запомнился? Нужен конкретный: «я сжёг траву и выиграл», а не «нормально».
2. Что было непонятно?
3. Хочешь сыграть с другом? В дуэль или на четверых?
4. Друзьям из веба: лучше или хуже веба и почему?

## Успех гейта

- 2 из 3 новичков за 30 с сами меняют направление и жмут силу.
- 2 из 3 новичков сами начинают 3 дуэли подряд.
- 2 из 3 называют конкретный момент.
- Друзья из веба говорят «не хуже».

Не прошло — PIVOT: чиним ядро или первые минуты, контент не добавляем. Скучно всем — обсуждаем KILL.
