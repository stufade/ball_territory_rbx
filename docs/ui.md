# UI M1: серый прототип

Код: `src/client/UI` (`init.luau` → `UI.start()`, `Menus.luau` меню, `Hud.luau` бой, `Theme.luau` цвета и виджеты). Всё строится кодом, без ассетов. Красота будет в M4.

**Масштаб.** Холст рассчитан на 960×540 «дизайн-пикселей», `UIScale = min(W/960, H/540)`, холст растягивается по длинной стороне. Телефон 390 px по высоте → масштаб 0,72. `ScreenInsets = DeviceSafeInsets` (вырезы).
**Кнопки.** Обычные ≥ 112 (≥ 80 px на телефоне), главные 150, кнопка силы круглая 200. Карточки шаров 212×280, в сетке 200×120.
**Стиль.** Тёмно-серый фон `#222429`, панели `#3A3D46`, чёрная обводка 3 px, скругление 14, шрифты FredokaOne (заголовки, кнопки) и BuilderSansBold (текст). Акцент (таймер, слово силы) жёлтый, главная кнопка синяя, «сильнее» зелёный, «слабее» красный, отмена красная. Места: синий, красный, зелёный, жёлтый.
**Иконка шара.** Цветной кружок с первой буквой названия (заглушка до M4).

## Порядок экранов (по `State.ph`)
| ph | Экран |
|---|---|
| `lobby` | «DUEL» (главная, синяя) и «4 PLAYERS» |
| `queue` | «Searching…», сколько людей, «Bots join in Ns», CANCEL |
| `pick` | «Choose your element», 4 карточки (intro) или сетка свободных (ffa), таймер |
| `draft` | слоты 3+3 по сторонам, чей ход, таймер; в свой ход 3 карточки `offer` и «ANY BALL FREE» (сетка свободных) |
| `choose` | «Winner's ball: X», карточки `left`, таймер 10 с |
| `match` | меню скрыто, HUD (приходит с `Match start`) |
| `wait` | «Waiting for a free arena…», BACK |
| `result` | корона и «YOU WIN» / «1ST PLACE» / «YOU LOSE», места, проценты, для дуэли «Rounds a : b», отсчёт до лобби |

**Подсветка «кто кого».** Рамка карточки и строка под ней: зелёная «Beats X» (`DSTRONG` против уже взятых шаров соперника, в `choose` против шара победителя), красная «Weak to X» (`DWEAK`). Рамка по перевесу.

## HUD в бою
- Углы сверху: карточка игрока 250×112 с портретом (`GetUserThumbnailAsync`, у бота «BOT»), именем, шаром и процентом земли, HP-полоской. Дуэль: сторона 0 слева, 1 справа, три кружка оставшихся шаров. 4 игрока: места 1 и 3 слева, 2 и 4 справа друг под другом.
- Сверху по центру полоска земли по цветам мест и под ней таймер раунда (`round − t`, красный в последние 10 с).
- Кнопка силы справа внизу: заливка снизу показывает заряд, готовая пульсирует (`UIScale` 1↔1,12), тап шлёт `Input power`.
- Баннеры: «CHOOSE DIRECTION 1.2» по `pu` снимка, крупный «FINAL!», «ROUND WON/LOST» 2,5 с.
- Подсказки `Match hint` одной строкой 4 с: `aim` «Drag to aim», `power` «Tap POWER!» со стрелкой на кнопку, `react` «Hit terrain for reactions!», `final` «FINAL — tap anywhere to steer».

## Анимации
Всплытие текста (UIScale 0,5→1, 0,25 с, Back), нажатие кнопки силы (0,9→1), пульс готовой силы. При `ReducedMotionEnabled` всё выключается.

## Допущения по протоколу
`round.a, b` читаются как выигранные раунды сторон 0 и 1, `me` в `draft` как сторона 0/1, HP полоски считаются от 100.
