# M4 — магазин

Три вкладки одного окна: `shop-balls.png`, `shop-spin.png`, `shop-skins.png`. Снято `tools/shot.sh` в Play на вьюпорте 1090×725, панель в кадре.

**BALLS.** Баннер шара дня — сцена: лучи, свечение, крупный шар, жирное имя, тир, таймер и две цены внутри баннера. Ниже сетка карточек с иконкой и тиром, без обрезанного ряда.

**SPIN.** Баннер — сцена того же шара дня: лучи, крупный герой, жирный заголовок. Под ним ряд шаров в толстой рамке тира, процент крупно, легендарный VOID шире и ярче. Кнопки пачек внутри карточки.

**SKINS.** Два целых ряда, цена на карточке не обрезана. Рамка — портрет, скин — шар в цвете, след — длинная полоса, сила — вспышка на всю карточку.

Кнопки внутри своих карточек на этом вьюпорте, на полосе `390x844` и на `1280x720` (замер `AbsolutePosition`, плохих 0). Телефон в руках не смотрели: NOT VERIFIED. `lune run tests/ui` — 1864 passed.
