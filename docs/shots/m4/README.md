# M4 — магазин

Три вкладки одного окна: `shop-balls.png`, `shop-spin.png`, `shop-skins.png`. Снято `tools/shot.sh` в Play на вьюпорте 1090×725, панель в кадре.

**BALLS.** Баннер шара дня (крупный шар, имя, тир, таймер, две цены) и сетка карточек с иконкой и тиром.

**SPIN.** Карточка: сверху лента шаров с призом дня по центру, под ней ряд шаров с процентом на каждом, кнопки пачек внутри карточки.

**SKINS.** Карточки с картинкой: рамка — портрет, скин — шар в цвете и узоре, след — полоса, сила — вспышка. Имя и цена на карточке.

Кнопки, которые не уехали в прокрутку, внутри панели на этом вьюпорте, на полосе `390x844` и на `1280x720` (замер `AbsolutePosition`, плохих 0). Телефон в руках не смотрели: NOT VERIFIED. `lune run tests/ui` — 1860 passed.
