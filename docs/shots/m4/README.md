# M4 — магазин и лента

Площадка лобби: `plaza.png` (стойка SHOP слева, арка PLAY справа, маяк по центру). Кадр снят `tools/shot.sh` и вместе с вьюпортом захватил панель Toolbox.

Снимки после переделки одного магазина на три вкладки: `shop-balls.png`, `shop-spin.png`, `shop-skins.png`. Окно Studio сначала было вне текущего пространства; его вывели на экран и сняли `tools/shot.sh`. На снимках курсор стоит на заголовке, белая обводка — фокус геймпада.

В Play раскладка снята числами на вьюпорте 1090×725 (`ShopPanel` 1021×576). Кнопки шаров и прокрутки целиком внутри панели. На вкладке скинов 30 карточек (`#Economy.LOOKS`); две кнопки нижней строки торчат в абсолютных координатах, потому что строка уже ушла под обрез прокрутки, сама карточка их держит. Лента: 24 иконки `Art.BALLS`, шансы 70/24/5/1/0, кнопка «SPIN 1,000» над лентой, низ кнопки выше низа панели.

Портрет 390×844 включён полосой `BTEmulate` внутри того же окна: панель 314×177 внутри полосы, на BALLS, SPIN и SKINS кнопки, которые видны больше чем наполовину, внутри панели и полосы. Лента на телефоне: 24 иконки, низ `SpinGo` (338) выше низа панели (392). Геймпад пальцами не нажимался: фокус встаёт на цену шара дня, Button B закрывает. `lune run tests/ui` — 1796 passed.
