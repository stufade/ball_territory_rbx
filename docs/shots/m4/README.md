# M4 — магазин

Три вкладки одного окна: `shop-balls.png`, `shop-spin.png`, `shop-skins.png`. Снято `tools/shot.sh` в Play на вьюпорте 1090×725, панель в кадре.

**BALLS.** Баннер шара дня — сцена на всю высоту: шар почти во весь баннер, лучи до краёв, имя размером заголовка, таймер и две цены внутри. Ниже сетка карточек без обрезанного ряда.

**SPIN.** Тот же заголовок и крупный шар. Под ним ряд процентов: карточка 1% (VOID) шире и выше, рамка золотая, процент по центру. Кнопка `SPIN 1,000` жёлтая, когда монет хватает.

**SKINS.** Два целых ряда. Превью заполняет карточку: след на всю ширину, вспышка на весь квадрат, скин и рамка крупно, цена на карточке.

Кнопки внутри своих карточек на этом вьюпорте, на полосе `390x844` и на `1280x720` (замер `AbsolutePosition`, плохих 0). Телефон в руках не смотрели: NOT VERIFIED. `lune run tests/ui` — 1864 passed.
