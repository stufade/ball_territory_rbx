# Ball Territory (Roblox): milestones

Источник решений — `docs/game-brief.md`. Правила игры — `../ball_territory_web/public/game.js`, ветка `main` веб-репозитория. Studio одна: scene-builder, tester и fun-critic работают строго по очереди.

**Статус:** принят 2026-11-09. M0-1, M0-2, M0-3 PASS (tester: синхронизация Rojo, `[BT] server boot`, правила работают внутри Roblox).

## M1: Серый прототип

**Цель:** игрок заходит, через 10–15 с играет раунд дуэли с подсказками, затем дуэли с драфтом и матчи 4 на всех против ботов и людей.
**Статус:** в работе. Приняты T1.1 (M1-1, M1-2, M1-3 PASS по lune), T1.2+T1.7, T1.3, T1.4, T1.5, T1.6 (по lune и линтерам, в Studio не проверены). T1.8 интеграция пройдена. Tester (`docs/test-reports/M1.md`): M1-4…M1-8 PASS, M1-9 PASS с ботом. Ждут живого плейтеста: M1-9 с двумя людьми, M1-6 с 2–3 клиентами, M1-10 визуально (MCP не снимает экран в Play). Затем гейт по `docs/playtest-m1.md`.
**Зависимости:** M0.

**Входит:**
- правила всех 27 шаров на Luau: поле 24×20, арена дуэли около 16×14, реакции, шипы, финал, боты, драфт 1-2-2-1, выбор шара проигравшим;
- сервер считает бой, клиент рисует по снимкам;
- арена-доска, повёрнутая к камере, аватары по бокам;
- HUD: портреты, оставшиеся шары, полоска земли, HP на шаре, «-16» и «+40», крупная кнопка силы;
- драфт: 3 случайных из всех 27 и 1 бесплатный «Любой шар», все шары открыты;
- первый раунд с 4 подсказками, экран победы с короной, 3–5 звуков, события воронки.

**Не входит:** сохранения, валюты, уровни, магазин, рулетки, задания, книга реакций, лобби, топовые анимации, музыка, иконка.

**Вердикт:** PROCEED / PIVOT / KILL — заполняется по решению пользователя.

## M1.5: Ощущение веба (добавлен 2026-11-09)

Пользователь посмотрел серый M1: «где иконки, где эффекты, абилки не дают отклика, арены нет». Ошибка плана: отклик и арт веба — часть ядра, без них гейт веселья не имеет смысла. Плейтест M1 отложен до конца M1.5.

- **V1** (принят директором по снимкам `docs/shots/v1`): поле, шары, эффекты, реакции, кнопка силы — один в один с вебом, арт растеризуется из `index.html` веба.
- **V2** (принят директором по снимкам `docs/shots/v2`, ждёт взгляда пользователя): арена и HUD как в Ball vs Ball (аватары по бокам, портреты, сердечки, иконка текущего шара), меню, драфт, выбор, экран победы с короной.

Критерий: на снимках Play (`tools/shot.sh`) рядом со скриншотами веба и референсами Ball vs Ball выглядит не хуже. Принимает директор по снимкам, затем пользователь.

## M1.6: Фидбек игры с другом (2026-11-09)

Пользователь сыграл с другом: «выглядит не плохо», но:

- **W4** (лобби, принят по снимкам `docs/shots/w4`; приглашение по ссылке и телепорт NOT VERIFIED): вместо меню на весь экран — площадка, бегаешь быстрее обычного, видно идущие матчи. Компактные кнопки. Создать лобби, пригласить друга, быстрый поиск вместе с другом.

## M2: Первые 3 минуты

**Цель:** новичок без слов понимает, что делает его шар, побеждает, получает шары и легендарный, и сам жмёт PLAY. Сценарий — бриф, «Первые 3 минуты» (решение пользователя 2026-11-10).
**Статус:** в работе, начат до плейтеста по решению пользователя.
- **T2.1** (сделан, тесты зелёные; снимки NOT VERIFIED — экран был заблокирован) обучение-мультик: сцены на настоящих правилах, ожидание действия, финал с победой. Снимки каждой сцены.
- **T2.2** (сделан, тесты зелёные; снимки и настоящий DataStore NOT VERIFIED — экран заблокирован, в Studio нет доступа к API; план съёмки `docs/shots/t2.2/README.md`) профиль с сохранением (коллекция, уровень, опыт), награда: 4 шара с анимацией, рулетка с легендарным, 2x опыт 15 мин, подсветка PLAY. `TEST_ALL_BALLS` выключается для игроков, остаётся отладочным флагом.

**Критерии:** обучение ≤ 90 с; в каждой сцене одно действие и ответ на него ≤ 1 с; ни одной строки длиннее 6 слов; победа в финале 100% на 50 прогонах; повторный вход сразу на площадку; коллекция и уровень переживают перезаход; на снимках каждая сцена читается с телефона.
