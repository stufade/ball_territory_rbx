# MOB-1: телефон (все экраны, кроме магазина)

2026-11-16, Claude Code (ui-designer). Проверка в окне Studio через `BTEmulate` (полоса 844×390 с заглушками кнопок Roblox, STICK и JUMP), числа через `execute_luau` (AbsolutePosition/Size, `TextBounds`, `TextFits`, переведены в px телефона). Device Emulator не использовался по решению пользователя: **реальный телефон NOT VERIFIED**.

Снимки: `docs/shots/mob/before.jpg`, `docs/shots/mob/after.jpg` (площадка, награда, задания, книга, драфт, матч; кадры в `docs/shots/mob/raw/`, b_* — до, a_* — после). Кадры заданий и книги «после» сняты до двух последних правок (ширина заданий, строка книги); эти правки проверены числами после перезапуска (`TextFits` true, крестики 45 px).

## Что сделано

- **Правило телефона** (`Theme.setPhone`, вызывается в `UI/init` на каждом fit): экран ниже 500 px устройства (у эмуляции — высота телефона) = телефон. На телефоне текст не мельче 22 дизайн-px (15,8 px вместо 14,4), площадка не держит место под список игроков Roblox (на телефоне его в углу нет), окна встают под кнопки Roblox (`Theme.windowY`). Смена правила пересобирает экраны, как смена холста. `ScreenInsets = DeviceSafeInsets` уже стоял на `BallUI`: вырез учитывается.
- **HUD площадки компактнее:** DAILY · QUESTS · BOOK · HELP · SHOP · SPIN одним рядом (было два ряда с дырами: SPIN под DAILY, SHOP под HELP), монеты в правом верхнем углу.
- **Книга реакций:** на телефоне сетка 7×6 вместо 6×7, окно 1090×442 под кнопками Roblox (было: заголовок под кнопками Roblox). Крестик 62 (45 px). Строка «+25 EACH NEW · EVERY 10…» больше не обрезается.
- **Задания:** крестик 62 (было 48 → 35 px). На телефоне окно 500 вместо 430, чтобы «WIN 2 4-PLAYER MATCHES» помещалось при крупном тексте.
- **Ежедневная награда:** окно ниже (верх 50 px вместо 28 px полосы): кнопки Roblox задевают только пустой угол рамки. Стиль дня 7 не тронут.
- **Драфт:** «FREE · ONCE» внутри кнопки ANY BALL под словом (было: висело на верхнем краю кнопки поверх неё).
